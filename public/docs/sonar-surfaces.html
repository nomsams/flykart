Surface-dependent sonar returns

Choose a surface in the 3D object inspector. In Open world, expand Sonar surfaces to apply one preset to all objects. The room, targets and surface assignments travel with scene saves and brain/lab exports.

PresetSimulated return
Original modelPreserves existing experiments: rounded targets return broadly; flat faces lose echoes at an angle.
Smooth / hardStrong facing return; steeper loss when the surface reflects the beam away.
Rough / hardLower facing return, broader angular response from scattered energy.
Fabric / foamStrong attenuation; close obstacles may still return, distant ones may disappear.
FoliageWeak, broad return; existing speckle causes intermittent readings near the threshold.

These are illustrative training coefficients, not measurements of your HC-SR04 or a particular fabric. Target size, angle, height, distance and the existing noise settings still matter. The module provides range or no echo, not material classification. No echo stays unknown in the scan map; it does not prove a clear passage. An absorbing obstacle still occludes objects behind it.

The model traces direct echoes and does not trace multiple reflections, corner amplification, transmission through materials, detailed leaves or sound propagation in water. It retains the sensor's minimum/maximum range and ping timing. Low floor patches and surfaces above the beam remain outside its useful sensing geometry.

The qualitative distinctions follow Banner's explanation of ultrasonic targets. MaxBotix explains corner reflections, which remain outside this simplified model. Measure your hardware against each relevant surface before treating these settings as calibrated.

Reproducible scenes and curricula

Save scene + targets stores geometry, robot pose and exact target positions. Open world also stores its exercise. Loading a scene starts a new episode with the current brain. It does not restore neuron voltage, elapsed time or collected rewards. In 3D, it retains the controller, wiring and learned task head; Undo returns to the previous scene. Export lab remains the option for the larger experiment bundle.

Expand Generalist training maps near the driving view. Choose All maps, Hard corners or individual checkboxes. At least one map must stay selected. V1 uses this set when Track set is Generalist. V2 has a separate checkbox so you can preview one map while evolving on several. Every chosen map is evaluated on the same seed list for every ghost and receives equal weight. Held-out seeds are also evaluated on every selected map. These test new conditions on the selected routes, not unseen routes. Choices are saved with exported brains.
